## 🌐 TCP/IP Model

Learned that networking communication is divided into layers so that each layer has a specific responsibility.

### 4 Layers

1. **Application Layer**
   - Provides network services to users/applications.
   - Examples: HTTP, HTTPS, DNS, SMTP
   - Main idea: **What the user wants**

2. **Transport Layer**
   - Provides end-to-end communication.
   - Main protocols: TCP and UDP
   - TCP provides reliable delivery.
   - Main idea: **How data is delivered**

3. **Internet Layer**
   - Handles IP addressing and routing.
   - Main protocol: IP
   - Determines how packets reach the destination.
   - Main idea: **Where the data needs to go**

4. **Network Access Layer**
   - Handles communication over the local network.
   - Examples: Ethernet and Wi-Fi
   - Works with physical transmission and MAC addressing.
   - Main idea: **How data physically moves**
