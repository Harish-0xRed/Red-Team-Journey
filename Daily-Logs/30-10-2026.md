## Today's Focus
**Wazuh Architecture & Sysmon Integration**

### 1. Wazuh Architecture

Studied the responsibilities of the main Wazuh components:

- **Wazuh Agent:** Collects configured endpoint logs and forwards events to the Wazuh Manager.
- **Wazuh Manager:** Receives events, processes them using decoders and detection rules, and generates alerts.
- **Wazuh Indexer:** Indexes and stores searchable event and alert data.
- **Wazuh Dashboard:** Provides a visual interface to monitor and investigate security data.

### 2. Understanding Windows Event Logs

Learned the difference between Windows Security Events and Sysmon Events.

- Windows generates security events such as Event ID 4625 (failed logon).
- Sysmon generates detailed system activity events.
- Both use separate Windows Event Log channels.
- Windows stores Event Log data in `.evtx` files.

Verified Sysmon installation on the Windows 11 endpoint.


Result:

- Enabled: True
- Recorded events: 11,215

### 4. Understanding Wazuh Agent Log Collection

Learned that the Wazuh Agent does not automatically collect every Windows log.

It collects configured event sources.

Without Sysmon, the agent can collect configured Windows event channels.

With Sysmon installed and its event channel configured in Wazuh Agent, it can also collect Sysmon events.
