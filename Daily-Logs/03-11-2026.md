### 2. Windows Event Log Architecture

### 3. Windows Event Channels
Studied the purpose of important Windows channels:

- Security — authentication and security auditing.
- System — operating system, drivers and services.
- Application — application-related events.
- Setup — Windows installation and setup events.
- Sysmon/Operational — Sysmon-generated events.

### 4. Windows Event Log Storage
Learned that Windows stores event records in `.evtx` files.

Default location:

```text
C:\Windows\System32\winevt\Logs\
```

Understood the difference between an Event Log channel and an EVTX file.

### 5. Practical Commands
Studied PowerShell commands for inspecting Windows Event Logs:

```powershell
Get-Service EventLog

Get-WinEvent -ListLog *

Get-WinEvent -LogName Security -MaxEvents 10
```

Also learned how to filter events using Event ID 4625.

### 6. Important Windows Security Event IDs
Introduced important authentication, account management and process-related events:

- 4624 — Successful logon
- 4625 — Failed logon
- 4634 — Account logged off
- 4648 — Explicit credentials used
- 4672 — Special privileges assigned
- 4688 — Process creation
- 4720 — User account created
- 4740 — User account locked out
- 1102 — Security audit log cleared
