### 📖 Chapter 18 - Special Permissions

#### Sticky Bit
- Learned the purpose of the Sticky Bit in shared directories.
- Understood that it prevents users from deleting files owned by other users.
- Learned that only the file owner or the root user can delete files inside a Sticky Bit directory.
- Identified Sticky Bit in `ls -l` output using:
  - `t` = Sticky Bit + Execute permission
  - `T` = Sticky Bit only (No execute permission for others)
- Practiced setting and removing Sticky Bit:
  - `chmod o+t`
  - `chmod o-t`
  - Numeric value: `1000`

### 📖 Chapter 18 - Links

#### Hard Links
- Learned how Linux stores files using:
  - Directory Entry
  - Inode
  - Data Blocks
- Understood that the inode stores metadata, not the file name or file contents.
- Learned that a Hard Link is another filename pointing to the same inode.
- Learned to view inode numbers using:
  - `ls -i`
  - `ls -li`
- Created Hard Links using:
  - `ln target link_name`
- Understood the meaning of the Hard Link count.

#### Symbolic (Soft) Links
- Learned that a Symbolic Link stores the pathname of another file.
- Created Symbolic Links using:
  - `ln -s target link_name`
- Identified Symbolic Links in `ls -l` output by:
  - `l` (file type)
  - `->` (target path)

#### Hard Link vs Symbolic Link
- Compared the advantages and limitations of both link types.
- Learned:
  - Hard Links share the same inode.
  - Symbolic Links store a pathname.
  - Hard Links survive deletion of one filename.
  - Symbolic Links become broken if the target file is deleted.
  - Hard Links cannot cross filesystems or link directories.
  - Symbolic Links can cross filesystems and link directories.
