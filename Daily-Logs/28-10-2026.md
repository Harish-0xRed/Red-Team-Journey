### Attack & Detect Lab — Architecture & Telemetry Pipeline (Phase 0)

#### Lab Architecture & Network Topologies
- Designed a dual-machine physical lab environment: ASUS TUF Windows 11 as the Monitored Endpoint / Target, and Acer One Linux Mint as the SIEM Server & Attacker workstation.
- Analyzed network virtualization modes:
  - **Bridged Mode:** Places VMs directly on the local network alongside personal devices, risking accidental packet leakage and unauthorized cross-device scanning.
  - **Host-Only Mode:** Creates an isolated, virtualized Layer 2 switch inside memory, ensuring complete air-gapped containment from the home LAN.
  - **NAT Mode:** Restricts inbound connections due to hypervisor address translation, preventing external nodes from initiating reverse-shell listener callbacks.

#### Sysmon (System Monitor) Internals
- Examined why native Windows Security Event Logging leaves detection blind spots (e.g., standard Event ID 4688 omitting command-line arguments and process parentage by default).
- Understood Sysmon architecture: a dual-layer system consisting of a kernel-level driver (`SysmonDrv.sys`) operating at Ring 0 and a user-mode service (`Sysmon64.exe`).
- Analyzed critical Sysmon Event IDs:
  - **Event ID 1 (Process Creation):** Exposes full CLI execution strings, parent process IDs (PPID), and cryptographic image hashes.
  - **Event ID 3 (Network Connection):** Binds active network sockets directly to specific process images and PIDs.
  - **Event ID 10 (ProcessAccess):** Detects memory handle requests targeting sensitive processes such as `lsass.exe`.
- Successfully deployed Sysmon v15.22 on the Windows target using the SwiftOnSecurity XML configuration.

## 💡 Lessons Learned
- In security operations, understanding underlying architecture is critical; tool syntax changes across environments, but telemetry markers remain consistent.
- A reverse shell requires direct inbound reachability to the listener; hypervisor NAT blocks unsolicited incoming sessions unless port forwarding or Host-Only/Bridged routing is established.
- Kernel-level drivers (Ring 0) intercept and document process activity before user-space evasion techniques can mask execution arguments.
- Centralized, immutable off-host logging is essential for incident investigation because attackers prioritize wiping local security logs upon host compromise.
