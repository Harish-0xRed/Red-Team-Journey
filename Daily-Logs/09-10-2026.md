## Lessons Learned

* `range()` controls the values used by a `for` loop.
* The stop value in `range()` is excluded.
* A negative step makes the loop count backward.
* A module is a Python program containing related functions and code that can be used by other programs.
* `import module` makes the module available to the program.
* `module.function()` accesses a function inside that module.
* `random.randint(1, 10)` returns a random integer from 1 through 10.
* Avoid naming Python files after modules or built-in Python names.
