## Key Learning
- The Wazuh server and Wazuh agent have different roles.
- A running agent service does not automatically mean the agent is connected.
- Network connectivity, agent logs, and dashboard status provide separate pieces of evidence.
- A Windows event does not automatically become a Wazuh alert; a detection rule must match the collected data.
