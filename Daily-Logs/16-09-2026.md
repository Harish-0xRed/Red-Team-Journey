## Lessons Learned

* Wireshark is a tool for capturing and analyzing network packets; understanding networking concepts is more important than memorizing filters.
* Wireshark can be thought of as a microscope for network traffic.
* A Wireshark filter is useful when I understand the network concept behind the filter.
* Example:
  `tcp.flags.syn == 1`
  means Wireshark should display packets where the TCP SYN flag is set.
* The correct learning flow is:

  Networking Concept
  ↓
  Packet Structure
  ↓
  Wireshark Field
  ↓
  Display Filter
  ↓
  Practical Analysis
