# Git Learning Log - 2026-08-07

## 📚 Today's Learning

### 🌐 DNS Deep Dive
- Understood that DNS does **not only return IP addresses**.
- Learned the purpose of different DNS record types:
  - **A** → Returns IPv4 address.
  - **AAAA** → Returns IPv6 address.
  - **CNAME** → Redirects one domain to another domain.
  - **MX** → Identifies the mail server for a domain.
  - **TXT** → Stores text data (SPF, DMARC, domain verification, etc.).
- Learned that different applications request different DNS record types:
  - Browser → A / AAAA
  - Mail server → MX
  - Domain verification services → TXT
  - Alias domains → CNAME

### 🔍 DNS Resolution Process
- Strengthened understanding of the DNS lookup flow:
  1. Browser checks DNS cache.
  2. Recursive DNS checks its cache.
  3. Root DNS redirects to the correct TLD server.
  4. TLD server redirects to the Authoritative DNS server.
  5. Authoritative DNS returns the requested DNS record.
  6. Recursive DNS caches the result.
  7. Browser receives the response and caches it according to the TTL value.

- Important realization:
  - **Root DNS does not know the website IP.**
  - **TLD DNS does not usually know the website IP.**
  - **Only the Authoritative DNS server stores the actual DNS records.**
