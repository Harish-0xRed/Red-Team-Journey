### 📚 Today's Understanding
- IP address identifies the **host/device**.
- A port identifies the **network service/application** on that host.
- Basic model:
  - `IP Address → Which machine?`
  - `Port → Which service?`
- Example:
  - `192.168.1.10` → Host
  - `192.168.1.10:80` → Host + Port 80
- Common ports introduced:
  - `22` → SSH
  - `53` → DNS
  - `80` → HTTP
  - `443` → HTTPS
  - `25` → SMTP
  - `21` → FTP
- Started connecting the concepts:
  - `IP → Port → TCP connection → HTTP/HTTPS → Request → Response`
