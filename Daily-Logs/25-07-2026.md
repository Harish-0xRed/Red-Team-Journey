## 💡 Lessons Learned

- `mktemp -d` creates a secure temporary working directory.
- `cp` protects the original file by creating a working copy.
- `xxd -r` converts a hexadecimal dump back into its original binary format.
- The `file` command should always be used to identify unknown files before extracting or opening them.
- Compression formats can be nested multiple times, requiring repeated investigation.
- Linux investigations follow a simple workflow:

```text
Identify
    ↓
Transform
    ↓
Identify Again
    ↓
Repeat
```
