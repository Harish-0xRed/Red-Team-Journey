## Lessons Learned

* **MTU** = maximum size of an IP packet that can be carried over a network link.
* **MSS** = maximum amount of TCP payload carried in one TCP segment.
* **Sequence Number** = identifies the position of the first byte of TCP data.
* **Next Sequence Number** = current sequence number + TCP payload length.
* **Acknowledgment Number** = the next byte the receiver expects.
* **Duplicate ACK** can indicate that the receiver is still waiting for a missing sequence.
* **SACK** provides additional information about data that was received even though an earlier segment is missing.
* **Receive Window** = amount of unacknowledged data the receiver is currently willing to accept.
* **Window Scaling** allows TCP to advertise a much larger receive window.
* Wireshark can display **relative sequence numbers** to make large TCP sequence numbers easier to understand.
* The TCP handshake is important when analyzing negotiated TCP features such as window scaling.
* TCP concepts must be understood first before interpreting Wireshark fields and filters.
