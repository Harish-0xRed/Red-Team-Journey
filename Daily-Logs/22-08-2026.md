## 💡 Lessons Learned
- HTTP is plain ASCII text that can be crafted, intercepted, and manipulated directly[cite: 2].
- HTTPS encrypts data in transit across the wire, but does not stop backend application vulnerabilities (SQLi, IDOR, RCE)[cite: 2].
- The double CRLF (`\r\n\r\n`) is the strict boundary that separates HTTP headers from the body[cite: 2].
- URL fragments (`#`) are processed only by the client browser and are never sent across the wire to the web server[cite: 2].
- Stealing a valid session cookie bypasses primary authentication mechanisms because the cookie represents the authenticated state[cite: 2].
