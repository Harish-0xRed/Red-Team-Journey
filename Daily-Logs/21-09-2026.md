## Lessons Learned

* A large PCAP does not mean every packet needs to be manually inspected.
* The goal of traffic analysis is to reduce a large amount of data into useful evidence.
* Wireshark features should be selected based on the evidence required, not simply because a tutorial tells us to use them.
* The core investigation mindset is:

  Question
  → What do I need to know?
  → What evidence can answer it?
  → Where can I find that evidence?
  → Which tool can expose it?
  → Analyze
  → Verify
  → Conclude

* 10.9.11.135 is currently a primary investigation candidate, not a confirmed infected host.
* ARP can be used to investigate the relationship between an IPv4 address and a MAC address on a local network.
* Packet Details can provide deeper protocol information after identifying the relevant packet.
* Good SOC investigation requires evidence-based reasoning rather than guessing.
