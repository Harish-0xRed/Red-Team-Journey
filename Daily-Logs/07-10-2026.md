## Lessons Learned

* A `while` loop keeps executing its block as long as its condition is `True`.
* `break` means **exit the loop completely**.
* `continue` means **skip the current iteration and start the next iteration**.
* `break` does not make the loop condition `False`; it directly changes the execution path out of the loop.
* Infinite loops can happen when there is no way for the loop to stop.
* Python conditions can directly use truthy and falsey values.
* Linux user management is an important system administration skill involving users, groups, passwords, shells, home directories, and account status.
