## Lessons Learned

* Python uses **indentation as part of its syntax** to define blocks.
* `:` means that a new block is expected.
* Flow control decides which part of the program gets executed.
* Program execution can be thought of as Python's "finger" moving through the code and sometimes skipping or moving to another path.
