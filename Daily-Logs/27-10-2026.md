## 📚 Today's Learning

### Advanced Concepts - Memory Management & Web Security
- **Core Memory Foundation:** PHP uses your physical **RAM** to store objects, arrays, and variables.
- **The Parking Lot Analogy:** Variables act like cars parked in a lot managed by a valet (Zend Engine). Sticky notes (`refcounts`) keep track of who holds a key to that address space.
- **Memory Pooling:** When a refcount drops to 0, PHP frees it internally but caches the space in an engine pool to allocate future variables quickly without bothering the Operating System.
- **Use-After-Free & Type Confusion:** Studied how engine-level logic flaws create dangling pointers (stale key fobs to cleared parking slots). Attackers exploit these by dropping custom payload bytes into the freed space right before the engine tries to read its old trusted variable, causing type confusion and full remote code execution.

#### 4. Virtualization Network Sandboxing
- **Bridged Networks:** Connects virtual machines directly to your physical interface card, pulling a live IP from your home router. This puts your home devices at risk of accidental infection or exposure from vulnerable targets like Metasploitable.
- **Host-Only Networks:** Isolates target and attacking machines inside a completely closed, virtual software switch within your computer's RAM. It acts as an air-gapped sandbox, blocking malware and exploit traffic from leaking onto your physical household network.

## 💡 Lessons Learned
- **PowerShell vs Linux syntax:** Linux uses forward slashes (`/`) and `mkdir`, while Windows uses backslashes (`\`) and `New-Item -ItemType Directory`.
- **Typo Verification:** Always run `Get-ChildItem` (or `ls`) to verify file names exactly as they are written when archive commands fail.
- **Sysmon Flags:** Automated scripts on headless servers require the `-accepteula` switch to bypass user-interface confirmation boxes.
- **Defensive Sandboxing:** Never expose intentionally broken, vulnerable training targets to a Bridged network. Keep testing environments inside a Host-Only bubble.
